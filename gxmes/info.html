NullG*mes is a website with some Flash G*mes available to play. There are currently g*mes available. This website was made with the goal of letting people still play old Flash g*mes after Flash shut down.

 

NullG*mes uses GitHub to host files and Ruffle to run Flash content. Some g*mes are also regular HTML g*mes found online.

 

This g*mes website was originally based on the flasharchive repo by selenite-cc. Nullboy000 added hundreds more g*mes and converted it into a proper website instead of standalone HTML files.

 

Feel free to fork this project or use it as a base for your own archive. Just give proper credit to both selenite-cc and Nullboy000.

 

Currently incompatible g*mes:

Run series, Fancy Pants Adventure series, Super Smash Flash 2, Burrito Bison
